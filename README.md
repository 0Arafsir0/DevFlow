
# DEVFLOW

A full-stack team project management and collaboration platform.

## Overview

DEVFLOW is a SaaS-style application designed to help teams
manage workspaces, projects, tasks, and collaboration through
a centralized platform.

## Technology Stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Real-time: Socket.IO
- Authentication: JWT and Refresh Token Rotation
- Testing: Vitest, Supertest, Playwright
- Infrastructure: Docker
